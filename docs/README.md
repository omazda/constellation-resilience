# Исследование по кейсу

Три документа — результат прогонов на `Данные/*.json` через официальный `Расчетный модуль/geometry.py`.
Числа в них воспроизводимы командами из раздела «Как перепроверить» каждого файла и служат
источником для `docs/REPORT.md`, который пойдёт жюри.

| Документ | О чём | Кому нужен |
|---|---|---|
| [PARAMETERS.md](PARAMETERS.md) | все параметры, влияющие на результат, с замерами чувствительности; ловушки расчёта | всем, кто трогает `core/` |
| [EXTENSIONS.md](EXTENSIONS.md) | показатели сверх обязательных: резерв маршрутов, критические аппараты, доставка с задержкой, кратность покрытия | тем, кто делает анализ устойчивости и отчёт |
| [MODEL.md](MODEL.md) | событийно-периодическая контактная модель: доказательства, замеры, риски | только после того, как сеточное ядро сошлось с эталоном |
| [SURROGATE.md](SURROGATE.md) | обучаемый суррогат проектного пространства: выбор архитектуры, генерация данных на GPU, границы применения | для интерактивного подбора конфигурации, после сходимости ядра |

## Выводы в одну строку каждый

1. **Доступность и максимальный перерыв не зависят от алгоритма маршрутизации** — это достижимость
   в графе. Расхождение с `tools/golden.py` всегда означает ошибку модели, а не «другой подход».
2. **Клиентские пункты не ретранслируют.** Наивный обход графа завышает доступность до +11 п.п.,
   и только на деградированных сценариях — там, где делаются выводы.
3. **`min_elevation_deg` — самый чувствительный параметр**: 5° против 10° это 100 % против 96.7 %.
   Трогать его для «улучшения» результата нельзя, ТЗ фиксирует его при сравнении вариантов.
4. **Метрика зависит от сетки**, поэтому варианты сравниваются только на одинаковом шаге.
5. **Сценарий 04 ломается целиком из-за геометрии**: при ISL 2000 км хорда между соседями по
   плоскости 2700 км, все внутриплоскостные связи исчезают (0 из 3456).
6. **Полная группировка выполняет цель, но резерва нет**: два непересекающихся маршрута существуют
   лишь 16–37 % времени.
7. **Узкое место — единственный шлюз.** Второй шлюз даёт +37 п.п. там, где перебор RAAN даёт +10.
8. **Допуск по задержке 10 минут выводит сценарий 04 на цель**, а первую очередь не спасает —
   это разные диагнозы: разрыв сети против отсутствия покрытия.
9. **Межспутниковая топология точно периодична с половиной периода обращения**, внутриплоскостные
   связи постоянны. На этом строится событийная модель.
10. **Сеточный движок обязателен в любом случае** — он путь к сходимости с эталоном и проверка
    для всего остального.
