# Изменения

Новое сверху. Одна строка на заметное изменение.

## Сборка стенда

- Полоса суток вместо ползунка: весь горизонт показан сразу, наведение мгновенно переводит глобус
  в этот момент. Возможно потому, что пакет `compute` привозит все 720 отсчётов разом — при
  перемотке не делается ни одного запроса к серверу.
- Глобус переведён с запросов `snapshot` на кадры, собираемые из бинарного пакета (`useResult.ts`):
  позиции, активность, рёбра и маршруты лежат в CSR и разбираются без копирования.
- Анимации перехода между кадрами во всех слоях globe.gl обнулены — штатные 300 мс превращали
  перемотку в кашу с задержкой.
- Следы аппаратов за 8 отсчётов: по неподвижной точке не видно, куда летит спутник.
- Насечки периода повторения межспутниковой топологии на полосе суток — половина периода
  обращения, 47.75 мин для орбиты 550 км (доказательство — `docs/MODEL.md`).
- Карта: границы стран и города-миллионники (Natural Earth 110m, вариант по умолчанию —
  фактический контроль территории, а не признание; 395 городов с русскими названиями). Данные
  лежат локально в `frontend/public/geo`, интернет на показе не нужен.
- Тема «ультрафиолет»: три цветовые шкалы (`uv`, `ion`, `graphite`), свечение кодирует живое
  состояние и не используется как украшение. Тёмная тема по умолчанию, переключатель сохранён.
- Новое сообщение `analysis`: резерв маршрутов, критические аппараты, кратность покрытия и
  доставка с допуском по задержке — то, чего не видно по обязательным показателям. Отдельная
  вкладка «Устойчивость» в интерфейсе.
- `core.metrics.reserve_profile` — распределение числа непересекающихся маршрутов по горизонту.
- Раскладка: полоса суток перенесена внутрь колонки глобуса. Во всю ширину она проходила под
  правой панелью и не принадлежала ни одной колонке.
- Раздел «Ограничения» в README приведён в соответствие с кодом: экран собран, выгрузка по кнопке
  работает — прежний текст остался от предыдущего состояния сборки.

## Первая сборка

- Расчётное ядро (`backend/core`): сценарий, сеть, маршрутизация, показатели, доставка с задержкой.
  Сходимость с эталоном `tools/golden.py` на всех четырёх сценариях, 73 теста.
- WebSocket-слой: весь обмен по `/ws`, бинарный пакет результата, кеш по хешу сценария.
- Фронтенд на Nuxt 4 (SPA) и Nuxt UI v4, глобус на globe.gl.
- Один образ Docker из двух стадий, запуск `docker compose up --build`.
- Документация: README, `docs/PROTOCOL.md`, `docs/ARCHITECTURE.md`, `docs/REPORT.md`.
